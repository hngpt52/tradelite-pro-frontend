# TradeLite Pro UI Components List

Based on the analysis of Fey.com's design patterns, here's a comprehensive list of UI components needed for the TradeLite Pro redesign.

## 1. Layout Components

### Sidebar Navigation
- Vertical sidebar with logo at top
- Icon + text navigation items
- Active state highlighting
- Collapsible on mobile
- User profile section

### Main Layout
- Dark theme container (near-black background)
- Content area with proper padding
- Footer with branding and attribution

### Card Containers
- Rounded corners (medium radius)
- Subtle background color distinction
- Optional header with title
- Consistent padding
- Hover states for interactive cards

## 2. Navigation Components

### Sidebar Menu Items
- Home/Dashboard
- Simulations
- Analytics
- Settings
- Account/Profile

### Tab Navigation
- Horizontal tabs for sub-navigation
- Active state indicator
- Consistent spacing

### Breadcrumbs
- Simple path indicators
- Separator elements

## 3. Data Display Components

### Data Tables
- Clean row styling
- Column headers
- Numeric value alignment
- Positive/negative value indicators (green/red)
- Sortable columns

### Charts and Graphs
- Line charts for time series data
- Area charts for volume
- Candlestick charts for price data
- Consistent axis styling
- Legend components
- Time period selectors (1D, 1W, 1M, etc.)

### Stat Cards
- Large number display
- Label text
- Change indicator (with percentage)
- Trend direction icon

### Market Overview Grid
- Card-based layout
- Company logo/icon
- Ticker symbol
- Current price
- Change amount and percentage

## 4. Form Components

### Input Fields
- Text inputs with proper padding
- Dark background with lighter border
- Focus states
- Label positioning
- Error states

### Dropdowns/Select
- Custom styling matching inputs
- Dropdown menu styling
- Selected state

### Buttons
- Primary action (filled)
- Secondary action (outline)
- Tertiary action (text only)
- Icon buttons
- Loading states

### Toggle/Switch
- On/off states
- Animation

## 5. Feedback Components

### Toast Notifications
- Success/error/info states
- Dismissible
- Auto-dismiss timing
- Positioning

### Modal Dialogs
- Overlay background
- Card container
- Header with close button
- Action buttons
- Various sizes

### Loading States
- Spinner animation
- Skeleton loaders for content
- Progress indicators

## 6. Authentication Components

### Login Form
- Email/username input
- Password input with show/hide
- Remember me checkbox
- Forgot password link
- Submit button
- OAuth alternatives

### Registration Form
- Input fields for user details
- Password requirements
- Terms acceptance checkbox
- Submit button

### Pricing Cards
- Tiered pricing display
- Feature lists
- CTA buttons
- Highlighted recommended plan

## 7. Dashboard Components

### Welcome Header
- User greeting
- Date display
- Quick action buttons

### Summary Widgets
- Performance overview
- Recent activity
- Alerts/notifications

### News Feed
- Article cards
- Timestamp
- Source attribution
- Category tags

## 8. Simulation Components

### Simulation Form
- Asset selector
- Strategy selector
- Parameter inputs
- Time period selector
- Run button

### Results Display
- Performance metrics
- Chart visualization
- AI-generated insights
- Action recommendations

## 9. Utility Components

### Search Bar
- Input field with icon
- Keyboard shortcut hint
- Results dropdown

### Tooltips
- Information tooltips
- Hover triggers
- Positioning

### Tags/Badges
- Status indicators
- Category labels
- Notification counters

### Icons
- Navigation icons
- Action icons
- Status indicators
- Consistent sizing and styling

## 10. Typography System

### Headings
- H1: Page titles
- H2: Section headers
- H3: Card headers
- H4: Sub-section headers

### Body Text
- Regular paragraph text
- Small/caption text
- Link styling
- Emphasis styling

### Data Typography
- Numeric values
- Percentage changes
- Currency formatting
- Date/time formatting

## 11. Color System

### Base Colors
- Background: Near-black (#0c0c12)
- Surface: Dark gray (#1f1f2c)
- Border: Medium gray (#333342)
- Text: White/light gray

### Accent Colors
- Primary: Blue (#0066cc)
- Success: Green (#10b981)
- Warning: Amber (#f59e0b)
- Error: Red (#ef4444)

### Data Visualization Colors
- Chart lines
- Area fills
- Bar colors
- Consistent palette for categories

## 12. Responsive Behavior

### Breakpoints
- Mobile: < 640px
- Tablet: 640px - 1024px
- Desktop: > 1024px

### Mobile Adaptations
- Sidebar collapses to hamburger menu
- Stacked layouts replace grid layouts
- Simplified charts
- Touch-friendly tap targets
